## 1. ภาพรวมการแข่งขัน (Concept & Format)

* **สโลแกน:** "หนึ่งวัน พิสูจน์ฝีมือ — สร้างจริง แข่งจริง พาทีมคุณขึ้นเป็นแชมป์"
* **รูปแบบการแข่งขัน:** Hackathon 1 วันเต็ม สำหรับทีมนักพัฒนาตัวแทนบริษัท (3–4 คน/ทีม รับไม่เกิน 20 ทีม)
* **กระบวนการ:** `Idea (ไอเดีย) → Prototype (ต้นแบบ) → Live Demo (สาธิตจริง)`
* **โจทย์ใหญ่:** **AI FOR BANGKOK** — สร้าง AI Product หรือระบบที่แก้ปัญหาเมืองกรุงเทพฯ ได้จริงภายใน 1 วัน

## 2. ธีมและโจทย์การแข่งขัน (3 Challenge Themes)

เลือกแก้ปัญหาเมืองกรุงเทพฯ **1 ใน 3 แนวทาง** ดังนี้:

### ธีมที่ 1: Smart Mobility & Traffic (การเดินทางและจราจร)
* แก้ปัญหาการจราจร ขนส่งสาธารณะ หรือการเดินทางในเมือง
* **ตัวอย่าง Use Case:**
  * พยากรณ์รถติดล่วงหน้า
  * แนะนำเส้นทางแบบเรียลไทม์
  * วิเคราะห์จุดเสี่ยงอุบัติเหตุ

### ธีมที่ 2: Civic & Public Service Access (บริการภาครัฐและข้อมูลเมือง)
* ช่วยให้คนกรุงเทพฯ เข้าถึงบริการภาครัฐและข้อมูลเมืองได้ง่ายขึ้น
* **ตัวอย่าง Use Case:**
  * ระบบแจ้งปัญหาเมือง
  * ติดตามสถานะเรื่องร้องเรียน
  * ระบบตอบคำถามประชาชนอัตโนมัติ

### ธีมที่ 3: Urban Living & Environment (คุณภาพชีวิตและสิ่งแวดล้อม)
* ยกระดับการใช้ชีวิตและสภาพแวดล้อมของคนเมือง
* **ตัวอย่าง Use Case:**
  * ระบบจัดการขยะอัจฉริยะ
  * ตรวจวัดและแจ้งเตือนคุณภาพอากาศ
  * ระบบช่วยส่งเสริมธุรกิจรายย่อยในเมือง

## 3. สิ่งที่ต้องส่งในวันแข่งขัน (Submission Checklist)

1. **Working Prototype:** ต้นแบบที่รันได้จริง พัฒนาเป็น Web / Mobile / Desktop ที่ตอบโจทย์ปัญหาเมืองที่เลือก
2. **AI Integration:** มีอย่างน้อย 1 ฟีเจอร์ที่เชื่อมต่อกับ AI / API เป็นส่วนสำคัญ พร้อมแสดง Logic การทำงานและการเชื่อมโยง
3. **GitHub Repo:** โค้ดโครงการบน Public Repo หรือแชร์สิทธิ์ให้คณะกรรมการเข้าถึงได้
4. **Pitch Deck (ไม่เกิน 8 หน้า):**
   * Problem (ปัญหา)
   * Solution (วิธีแก้)
   * Architecture (สถาปัตยกรรมระบบ)
   * AI Integration (การเชื่อมต่อและใช้ AI)
   * Business หรือ Use Case
   * Next Steps (แผนพัฒนาต่อยอด)
5. **Live Demo:** สาธิตระบบจริง End-to-End ต่อหน้าคณะกรรมการ (ตั้งแต่รับข้อมูลจนถึงผลลัพธ์ หากใช้ Mock Data ต้องแจ้งให้ทราบ)
6. **วิดีโอสำรอง (Backup Video ความยาวไม่เกิน 3 นาที):** สำหรับเปิดกรณี Live Demo เกิดปัญหาหน้างาน

## 4. เกณฑ์การให้คะแนน (Scoring Criteria - 100%)

| สัดส่วน | เกณฑ์การตัดสิน | รายละเอียด |
| :---: | :--- | :--- |
| **30%** | **Functionality & Execution** | Prototype ทำงานได้จริง ขั้นตอนหลักครบถ้วน ระบบไม่ล่มระหว่างนำเสนอ |
| **25%** | **AI Integration Depth** | ใช้ AI/API แก้ปัญหาเชิงลึก มี Logic ชัดเจน และเชื่อมโยงกับการทำงานจริง |
| **20%** | **Innovation & Problem-Solution Fit** | ไอเดียสร้างสรรค์และตอบโจทย์ปัญหาของกรุงเทพฯ ได้ตรงจุด |
| **15%** | **Pitch & Business Viability** | อธิบายผลงานชัดเจน มี Use Case สมเหตุสมผล มีแนวทางพัฒนาต่อยอดทางธุรกิจ |
| **10%** | **UX / Design** | ใช้งานง่าย เข้าใจขั้นตอนการใช้งานได้ทันทีในช่วง Demo |
