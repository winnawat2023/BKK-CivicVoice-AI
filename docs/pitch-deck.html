02 / The Unsolved Gap

ทำไมแอปพลิเคชันอย่างเดียวจึงไม่พอ และทำไมสายด่วน 1555 จึงสายไหม้?

ช่องว่างขนาดใหญ่ระหว่างโลกดิจิทัลกับพฤติกรรมจริงของประชาชน

1

Digital Exclusion

ผู้สูงอายุ คนขับรถ และประชาชนทั่วไป ไม่สะดวกเปิดแอป ถ่ายรูป ปักหมุด GPS ในสถานการณ์ฉุกเฉิน แต่ทุกคน "สะดวกโทร 1555"

2

คู่สายเต็มช่วงวิกฤต

ฝนตกน้ำท่วมคนโทรพร้อมกันหลายร้อยสาย ต้องถือสายรอนาน 10-15 นาที ที่สำคัญ 30-40% โทรมาเพียงถามระเบียบราชการ (ทำบัตรประชาชนที่ไหน) แย่งคิวสายฉุกเฉิน

3

เสียงพูดไม่มี GPS

คนแจ้งบอกพิกัดด้วยคำพูดปากเปล่า: "หน้าตึกสีฟ้า ซอยแคบๆ ลาดพร้าว" เจ้าหน้าที่เขตลงพื้นที่จริงหาไม่เจอ เคสถูกดีดไปมากลายเป็นเรื่องค้างท่อ

03 / Solution Architecture

สถาปัตยกรรมระบบ BKK CivicVoice AI

เชื่อมโยง Contact Center ระดับ Enterprise สู่โมเดลภาษาไทยบนเซิร์ฟเวอร์ DGX

1. CITIZEN VOICE
โทรเข้าสายด่วน 1555 (Inbound PSTN / Mobile)
2. GENESYS CLOUD CX
Architect Inbound Flow + Data Action / Webhook (Org: ark-insights)
3. THAI AI ENGINE
Faster-Whisper (ASR) + Typhoon-1.5X-8B บน DGX 101
4. AGENT COPILOT
Interaction Widget เด้งสรุป 3 บรรทัด + 1-Click Dispatch เข้า 50 เขต
📡 Enterprise Security: HTTPS/WSS ตรงสู่โดเมน voiceai-demo.ark-insights.com (Let's Encrypt SSL)
⚡ Ultra-Low Latency: End-to-End Response Time ต่ำกว่า 1 วินาที ด้วยพลังประมวลผล NVIDIA GPU

05 / Live Demonstration

พิสูจน์ด้วยการโทรจริง สดๆ ต่อหน้าคณะกรรมการ

สาธิต 2 Scenario หลักที่แก้ปัญหา กทม. ได้อย่างเด็ดขาด

SCENARIO A (Zero Human Load)

สอบถามระเบียบราชการ กทม.

โทรศัพท์ถาม: "วันเสาร์เขตจตุจักรเปิดทำบัตรประชาชนไหม"
➡️ AI ตรวจจับ Intent แล้วดึง RAG คู่มือ กทม. ตอบกลับด้วยเสียงพูดจบในสายทันที ลดภาระสาย 1555 ได้ 30-40%

สถานะ: อัตโนมัติ 100% ไม่ต้องใช้เจ้าหน้าที่
SCENARIO B (Agent Copilot)

แจ้งเหตุเดือดร้อนฉุกเฉิน

โทรศัพท์แจ้งท่อแตก สุขุมวิท 50
➡️ หน้าจอ Genesys Agent Desktop เด้ง Live Transcript + สรุป 3 บรรทัด
➡️ เจ้าหน้าที่กดปุ่ม "1-Click Dispatch ส่งเรื่องเข้าเขตคลองเตย" จบงานใน 1 วินาที

สถานะ: Human-in-the-loop ลดเวลาคุยสายลง 50%
06 / Impact to Bangkok City

สร้างผลกระทบจริง ยกระดับคุณภาพชีวิตคนเมืองอย่างยั่งยืน

วัดผลได้จริงทั้งในมุมของประชาชนและฝ่ายบริหารกรุงเทพมหานคร

👥 เพื่อประชาชนชาวกรุงเทพฯ ทุกกลุ่ม

  • ✓ Zero Queue Waiting: โทร 1555 ติดทันที ไม่มีสายไม่ว่าง ไม่ต้องถือสายรอคิว
  • ✓ Digital Inclusion: ผู้สูงอายุ คนขับรถ และผู้พิการ เข้าถึงบริการรัฐได้อย่างเท่าเทียมผ่านเสียงพูด
  • ✓ Transparent Tracking: โทรกลับมาเบอร์เดิม AI จำเบอร์ได้ แจ้งความคืบหน้าเรื่องที่แจ้งทันที

🏛️ เพื่อการบริหารงานกรุงเทพมหานคร (BMA)

  • ✓ ลด AHT ของเจ้าหน้าที่ลง 50%: ไม่ต้องพิมพ์สรุปเอง AI คัดกรองและออก Ticket อัตโนมัติ
  • ✓ ลดภาระสาย 1555 ลง 30-40%: สายถามข้อมูลระเบียบ กทม. ถูก AI ตอบจบในสายทันที
  • ✓ ลดเรื่องค้างท่อใน 50 เขต: ปัญหาถูกส่งตรงฝ่ายตรงเขตตั้งแต่ครั้งแรก ข้อมูลพิกัดชัดเจน
