# คู่มือติดสปีดสำหรับสมาชิก: BKK CivicVoice AI
> **ฉบับเข้าใจง่ายใน 3 นาที:** เรากำลังทำอะไร ทำไมต้องทำ และฉันต้องกดอะไรบ้างในวันแข่ง

---

## 1. เรากำลังทำอะไร? (The Big Picture)

### ปัญหาที่ทุกคนเจอแต่ไม่มีใครแก้:
* คนกรุงเทพฯ เวลาเจอท่อแตก น้ำท่วม ไฟดับ **"ถนัดโทร 1555"** มากกว่าโหลดแอปมาถ่ายรูปปักหมุด โดยเฉพาะ **ผู้สูงอายุ และคนขับรถ**
* ผลคือ: **สายด่วน 1555 คู่สายไหม้ รอสายนาน 10-15 นาที** เพราะคน 30-40% โทรมาแค่ถามข้อมูลราชการ (เช่น ทำบัตรประชาชนวันเสาร์ที่ไหน)
* เวลาคนโทรมาแจ้งเหตุจริง บอกพิกัดด้วยเสียงพูด *"หน้าตึกสีฟ้า ซอยแคบๆ ลาดพร้าว"* เจ้าหน้าที่เขตลงพื้นที่จริงก็หาไม่เจอ เคสถูกดีดไปมา ค้างท่อในระบบกว่า 25%

### สิ่งที่เรา 4 คนกำลังสร้าง (BKK CivicVoice AI):
เราเปลี่ยนศูนย์สายด่วน 1555 ให้เป็น **AI-First Contact Center**:
1. **คนโทรเข้าเบอร์จริง (Genesys Cloud):** บอทรับสายทันที 0 วินาที
2. **ถ้าแค่ถามข้อมูลราชการ:** AI ตอบด้วยเสียงพูดภาษาไทยจบในสายทันที ไม่ต้องรอเจ้าหน้าที่
3. **ถ้าแจ้งเรื่องร้องเรียน:** AI ฟังภาษาพูด แกะชื่อถนน/ซอย รู้ว่าเป็นเขตไหน ออก Ticket เข้าสำนักงานเขตอัตโนมัติ
4. **ถ้าสายโอนมาหาคน:** บนหน้าจอเจ้าหน้าที่ (Agent Workspace) จะมี Widget ช่วยสรุป 3 บรรทัดพร้อมปุ่มกด 1 คลิกส่งเรื่องเข้าเขตทันที

## 2. โฟลว์การทำงานจริง (Data & Action Flow)

```
[ ประชาชนโทรเข้าเบอร์จริง ]
             │
             ▼
[ 1. คุณวัชระ (Genesys Cloud) ]
  • รับสายโทรศัพท์ แปลงเสียงพูดเป็นข้อความ (STT)
  • ส่ง Webhook มาที่ Backend
             │
             ▼
[ 2. คุณพีรพันธ์ (FastAPI + Typhoon/Gemma AI) ]
  • AI อ่านข้อความแล้วแยกทันที:
    - หมวดหมู่: ถนน / ทางเท้า / ไฟฟ้า / ขยะ
    - สถานที่ & สำนักงานเขต: เช่น "สุขุมวิท 50" -> "เขตคลองเตย"
    - ความเร่งด่วน: HIGH / MEDIUM / LOW
  • บันทึกเป็น Ticket และส่งต่อผ่าน WebSocket
             │
             ▼
[ 3. คุณอิทธิพล (Agent Widget บนหน้าจอคอม) ]
  • หน้าจอเด้งข้อความถอดเสียงสด + สรุปประเด็น 3 บรรทัด
  • เจ้าหน้าที่กดปุ่ม "1-Click ส่งเรื่องเข้าเขตคลองเตย"
             │
             ▼
[ 4. คุณชัยพร (Team Lead & Pitching) ]
  • โชว์ให้กรรมการดูบนเวที: "นี่คือระบบระดับ Enterprise ที่รันอยู่จริงบน Genesys Cloud ไม่ใช่แค่แชตบอทของเล่น"
```

## 3. เจาะลึกหน้าที่ของแต่ละคน (ใครทำอะไร ดูตรงนี้!)

---

### 👤 คุณวัชระ (Member 2: Genesys Cloud CX Engineer)
> **เป้าหมายของคุณ:** ทำให้โทรศัพท์โทรเข้าเบอร์จริงแล้วยิงข้อมูลมาที่ Backend ได้

* **สิ่งที่คุณต้องทำ:**
  1. เข้า Genesys Cloud CX Org `ark-insights`
  2. ไปที่ **Architect** สร้าง Inbound Call Flow ง่ายๆ มีเบอร์ทดสอบ 1 เบอร์
  3. ตั้ง Data Action ยิง Webhook (POST) มาที่ Backend URL:
     ```json
     {
       "interaction_id": "CALL-XXXX",
       "ani": "เบอร์คนโทร",
       "transcript": "ข้อความเสียงภาษาไทยที่ถอดได้"
     }
     ```
  4. ติดตั้ง Client Application (iframe) ให้เปิดไฟล์ Widget (`index.html`) บนหน้าจอ Agent Workspace
* **จุดที่สำเร็จ:** เมื่อใช้มือถือกดโทรเข้าเบอร์ Genesys แล้ว Backend ได้รับ Request

---

### 👤 คุณพีรพันธ์ (Member 3: AI Engine & Data Engineer)
> **เป้าหมายของคุณ:** เป็น "สมอง AI" รับข้อความภาษาไทยมา แล้วตอบกลับเป็น JSON ที่ถูกต้อง

* **สิ่งที่คุณต้องทำ:**
  1. เปิดไฟล์ `src/backend/main.py`
  2. ในฟังก์ชัน `classify_with_thai_llm`:
     * ตอนนี้ทำ Mock กฎเบื้องต้นไว้แล้ว ให้เชื่อมต่อ API Key จริงของ **Typhoon** หรือ **Gemma**
     * สั่ง System Prompt ให้คืนค่าเป็น JSON:
       ```json
       {
         "intent": "complaint หรือ inquiry",
         "category": "ถนน / ทางเท้า / ไฟฟ้า / ขยะ / ผิดกฎจราจร",
         "district": "ระบุชื่อเขต 1 ใน 50 เขต กทม.",
         "urgency": "low / medium / high",
         "summary_th": "สรุปสั้น 2 ประโยค",
         "suggested_action": "ฝ่ายโยธา/เทศกิจ/ความสะอาด"
       }
       ```
  3. ทำ endpoint RAG ดึงข้อมูลตอบคำถามบัตรประชาชน/ทะเบียนบ้าน
* **จุดที่สำเร็จ:** เมื่อยิงข้อความเข้ามา AI สกัดหมวดหมู่และเขตได้แม่นยำภายใน 2 วินาที

---

### 👤 คุณอิทธิพล (Member 4: Frontend Widget & Real-time Integration)
> **เป้าหมายของคุณ:** ทำหน้าจอที่เจ้าหน้าที่ Call Center ต้องมองเห็น ให้สวย ทันสมัย และใช้ง่าย

* **สิ่งที่คุณต้องทำ:**
  1. เปิดไฟล์ `src/frontend/widget/index.html` (ทำโครง Tailwind ไว้ให้แล้ว)
  2. เชื่อมต่อ WebSocket กับ Backend (`ws://localhost:8000/ws/agent/{interaction_id}`)
  3. เวลาสายโทรเข้ามา หน้าจอต้องแสดง:
     * **กล่องที่ 1:** ข้อความเสียงที่พูดสดๆ (Live Transcript)
     * **กล่องที่ 2:** AI สรุป 3 บรรทัด (ปัญหาคืออะไร / เขตไหน / เร่งด่วนไหม)
     * **กล่องที่ 3:** ปุ่มกด *"1-Click ส่งเรื่องเข้าสำนักงานเขต"* กดแล้วขึ้น Alert สำเร็จ
  4. รันไฟล์ `src/tests/simulate_call.py` เพื่อทดสอบว่าหน้าจอขยับตามข้อมูลจริงไหม
* **จุดที่สำเร็จ:** มีหน้าเว็บที่เปิดใน iframe ของ Genesys แล้วเห็นข้อมูลเด้งแบบเรียลไทม์

## 4. แผนการทดสอบแบบเห็นภาพ (ลองรันด้วยตัวเองใน 1 นาที)

ทุกคนสามารถทดสอบภาพรวมของระบบได้ทันทีบนเครื่องตัวเองตามขั้นตอนนี้:

1. **เปิด Terminal ที่ 1 (รัน Backend):**
   ```bash
   source venv/bin/activate
   uvicorn src.backend.main:app --port 8000 --reload
   ```
2. **เปิดหน้าจอ Widget:**
   * ดับเบิลคลิกเปิดไฟล์ `src/frontend/widget/index.html` บนเบราว์เซอร์ (Chrome / Safari)
3. **เปิด Terminal ที่ 2 (จำลองสายโทรเข้า):**
   ```bash
   ./venv/bin/python src/tests/simulate_call.py
   ```
4. **สังเกตผล:**
   * จะเห็นข้อความจำลองเสียงโทรเข้า *"ท่อระบายน้ำแตก สุขุมวิท 50"* ถูก AI วิเคราะห์และบันทึกเป็น Ticket อัตโนมัติทันที!
