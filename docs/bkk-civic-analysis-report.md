## 1. บทสรุปผู้บริหาร (Executive Summary)

จากการนำชุดข้อมูลเรื่องร้องเรียนจริงของคนกรุงเทพฯ ในรอบ 3 ปี มาวิเคราะห์เชิงสถิติ พบว่า:
1. **ปัญหาด้านกายภาพของเมือง (Physical Infrastructure) มีสัดส่วนสูงสุด:** กว่า 30% ของเรื่องร้องเรียนทั้งหมดกระจุกตัวอยู่ที่ **"ถนนชำรุด"** และ **"ทางเท้าพัง/กระเบื้องแตก"** ซึ่งเป็นปัญหาที่ส่งผลต่อความปลอดภัยในชีวิตประจำวันของประชาชนโดยตรง
2. **การทำผิดกฎจราจรและวินัยเมืองพุ่งสูงขึ้นอย่างมีนัยสำคัญ:** ปัญหาการจอดรถบนทางเท้า มอเตอร์ไซค์วิ่งบนทางเท้า และการขับรถย้อนศร ขึ้นมาติดอันดับ 1 ในปี 2568 และยังคงติด Top 3 ในปี 2569
3. **ปัญหาคอขวดและเรื่องค้างท่อ (Unresolved Backlog):** ในเขตเศรษฐกิจและชุมชนหนาแน่น (เช่น จตุจักร คลองเตย วัฒนา) มีอัตราการแก้ไขปัญหาสำเร็จอยู่ที่ประมาณ 71% – 76% ส่งผลให้มีเรื่องค้างท่อในระบบสะสมเฉลี่ย **24% – 28%**
4. **จุดอ่อนของกระบวนการเดิม:** ประชาชนจำนวนมากที่ติดต่อผ่านเสียง (เช่น โทรศัพท์เข้า 1555 หรือสำนักงานเขต) ข้อมูลมักตกหล่น หรือคัดแยกหมวดหมู่เพื่อส่งต่อหน่วยงานล่าช้า

## 5. การนำ Insight ไปออกแบบโซลูชัน BKK CivicConnect AI

ข้อมูลจริงเหล่านี้ทำให้ทีม ARK Insights มี **Data-driven Evidence** ที่แข็งแกร่งในการนำเสนอต่อหน้าคณะกรรมการ:

1. **Auto-Categorization Model (AI จัดหมวดหมู่แม่นยำ):**
   * เทรน / Prompt จูนโมเดล **Typhoon / Gemma** ให้เข้าใจหมวดหลัก Top 5 (ถนน, ทางเท้า, จราจร, ไฟฟ้า, ขยะ) และคู่คำภาษาพูดของคนกรุงเทพฯ (เช่น "กระเบื้องกระดก", "ไฟมืดตื๋อ", "น้ำเอ่อ", "มอไซค์วิ่งบนฟุตบาท")
2. **Priority Routing ไปยังสำนักงานเขต:**
   * เชื่อมโยงระบบ Entity Extraction เข้ากับฐานข้อมูล 50 เขต โดยระบบสามารถตรวจจับชื่อถนน/ซอย เช่น "อโศก", "สุขุมวิท 71", "ลาดพร้าว" แล้วระบุเขตปลายทาง (วัฒนา, คลองเตย, จตุจักร) ได้ทันที
3. **Agent Assist SLA Calculator (ลดเรื่องค้างท่อ):**
   * แสดง Benchmark ระยะเวลาเฉลี่ยบนหน้าจอ Genesys Agent Widget เพื่อให้เจ้าหน้าที่สามารถแจ้งประชาชนในสายได้ทันทีว่า "เรื่องลักษณะนี้ในเขตคลองเตยใช้เวลาแก้ไขเฉลี่ยประมาณกี่วัน" เพิ่มความโปร่งใสและความพึงพอใจของประชาชน
