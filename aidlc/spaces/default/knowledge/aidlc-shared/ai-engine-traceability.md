Only the four items assigned by the team lead:

* **A** Core FastAPI backend
* **B** Thai LLM prompt: intent, category, 50 districts, urgency
* **C** Civic RAG, answer inside the call
* **D** WebSocket gateway: live transcript & summary → Agent Widget

`inception/requirements-analysis/requirements.md` (FR/NFR ids).

Legend: ✅ done and tested · ⚠️ partial / deviation · ❌ not done · ⏭ belongs to another team member / outside the four items.
